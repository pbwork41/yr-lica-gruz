# Юрлица · Грузоперевозки (yr.lica_gruz)

Внутренняя платформа учёта заявок по юрлицам: заявки с авторасчётом прибыли, дашборд с недельным распределением дивидендов, расходы, контрагенты. Вход по логину/паролю.

База данных — общий проект Supabase `gruzchiki`, схема **legal** (изолирована от платформы грузчиков).

---

## Что нужно сделать один раз перед деплоем

### 1. Открыть схему `legal` для API в Supabase
Это обязательный шаг — иначе приложение не увидит таблицы.

1. Supabase → проект **gruzchiki** → **Settings** → **API**.
2. Блок **Exposed schemas** (или Data API → Exposed schemas).
3. Добавь в список схему **`legal`** рядом с `public`. Сохрани.

### 2. Взять anon-ключ
Там же, Settings → API → блок **Project API keys** → скопируй ключ **anon / public**
(он уже вписан в инструкцию ниже, но проверь, что совпадает).

## Что внутри
- **Заявки** — создание/редактирование, авторасчёт (НДС 5%, УСН 10%, СЗ 3%+6%, логист 5%, реклама 5%), водопад расчёта, доли 60/40.
- **Дашборд** — выбор периода, блок «К распределению» (только оплаченные, по дате оплаты), дебиторка, рекламный фонд с остатком, налоги к уплате, оборот по контрагентам.
- **Расходы** — реклама списывается из фонда, прочее уменьшает прибыль перед делёжкой.
- **Контрагенты** — реквизиты + ставки (час, контейнер 20/40, выплаты 20/40), дата последнего заказа.

## Ставки расчёта (зашиты в lib/calc.js и в БД)
НДС 5% · УСН 10% · СЗ 3% + 6% · логист 5% · реклама 5% · доли 60/40.
Меняются в одном месте — `lib/calc.js` (фронт) и представление `legal.orders_calc` (БД).

## Безопасность
Таблицы `legal.*` защищены RLS: без входа данные недоступны даже с anon-ключом.
Платформа грузчиков (`public.*`) не затронута.
